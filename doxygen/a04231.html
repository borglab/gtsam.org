gtsam::ExtendedPose3< K_, Derived > Class Template Reference

Detailed Description

template<int K_, class Derived>
class gtsam::ExtendedPose3< K_, Derived >

Lie group SE_k(3): semidirect product of SO(3) with k copies of R^3.

State ordering is (R, x_1, ..., x_k) with R in SO(3) and x_i in R^3. Tangent ordering is [omega, rho_1, ..., rho_k], each block in R^3.

The manifold dimension is 3+3k and the homogeneous matrix size is 3+k. Template parameter K can be fixed (K >= 1) or Eigen::Dynamic.
