gtsam::SmartProjectionFactorBase< CAMERA > Class Template Reference

Detailed Description

template<class CAMERA>
class gtsam::SmartProjectionFactorBase< CAMERA >

Common base for monocular smart projection factors.

It triangulates the observed landmark, caches the result, and provides the shared error and linearization implementations. Derived factors decide how their variables are converted into cameras by overriding SmartFactorBase::cameras.

◆ totalReprojectionError()

template<class CAMERA>
double gtsam::SmartProjectionFactorBase< CAMERA >::totalReprojectionError ( const Cameras & cameras,
std::optional< Point3 > externalPoint = {} ) const
inline

Calculate the error of the factor.

This is the log-likelihood, e.g. \( 0.5(h(x)-z)^2/\sigma^2 \) in case of Gaussian. In this class, we take the raw prediction error \( h(x)-z \), ask the noise model to transform it to \( (h(x)-z)^2/\sigma^2 \), and then multiply by 0.5.
