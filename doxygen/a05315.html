gtsam::MultifrontalParameters Struct Reference

Detailed Description

Parameters for gtsam::MultifrontalSolver.

These parameters are intentionally defined in a standalone header so they can be referenced from nonlinear optimizer parameter types without pulling in the full multifrontal solver headers.

Note
LM-style damping behavior is controlled by NonlinearMultifrontalSolver and its damping parameters; MultifrontalParameters only controls structure, traversal, and reporting.
