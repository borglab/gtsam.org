gtsam::NavState Class Reference

Detailed Description

Navigation state: Pose (rotation, translation) + velocity Following Barrau20icra, this class belongs to the Lie group SE_2(3).

This group is also called "double direct isometries”.

NOTE: While Barrau20icra follow a R,v,t order, we use a R,t,v order to maintain backwards compatibility.
