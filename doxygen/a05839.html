gtsam::LeggedCombinedFixedLagSmoother Class Reference

Detailed Description

Fixed-lag smoother with CombinedImuFactor bias evolution.

This variant keeps the same contact-episode smoother structure as LeggedFixedLagSmoother, but replaces the ImuFactor2 motion model with event-to-event CombinedImuFactor links. Pose, velocity, and bias are stored as separate graph variables at each contact event, and the bias is allowed to evolve with a random walk between events.

In practice this is the smoother analogue of moving from a fixed, subtractive IMU bias estimate to an explicitly estimated bias trajectory. It serves as an example of how to upgrade a contact-event smoother from simple preintegration with one shared bias key to combined preintegration with per-event bias states.
