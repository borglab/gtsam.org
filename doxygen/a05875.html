gtsam::LieGroupPreintegration Class Reference

Detailed Description

IMU preintegration using the SE_2(3) Lie-group structure of NavState.

Unlike ManifoldPreintegration, each increment is applied with the group exponential map. In Legacy factor-error mode, factors using this backend evaluate their residual with the SE_2(3) logarithm.
