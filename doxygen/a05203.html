gtsam::KeyInfo Class Reference

Detailed Description

Ordered key dimensions and offsets in one flattened variable vector.

The map provides lookup by key. ordering() defines block order, each entry stores the matching order index and scalar prefix, and numCols() is the sum of all block dimensions.
