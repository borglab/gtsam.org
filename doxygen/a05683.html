gtsam::GnssMeasurementBase Struct Reference

Detailed Description

Base class storing common members for GNSS measurement factors.

Shared by pseudorange and carrier phase factors. The measurement field is in meters (i.e. for carrier phase factors it is already multiplied by the wavelength, lambda * phi_cycles).
