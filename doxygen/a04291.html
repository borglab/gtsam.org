gtsam::so3::Kernel Struct Reference

Detailed Description

Kernel: M(ω) = a I + b Ω + c Ω² with radial derivatives db,dc for Fréchet.

Right variants flip b→-b, db→-db (no recompute of Ω/Ω²). Keep a pointer to Local: Kernel methods above return a const & to prevent having a pointer to a temporary.
