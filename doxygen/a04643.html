gtsam::DiscreteBoundaryFactor Class Reference
Discrete

Detailed Description

A discrete probabilistic factor which computes its values from the continuous factors connected to it and a set of values.

Helps in computing the discrete probabilities at the boundary of discrete and continuous factors.
