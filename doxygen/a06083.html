gtsam::DiscreteScenario Class Reference

Detailed Description

A scenario defined by discrete ground-truth measurements over time.

This class stores time-stamped ground truth values for pose, angular velocity, linear velocity, and linear acceleration. When queried for a value at a specific time t, it performs linear interpolation for vector quantities and manifold interpolation for poses. If t is outside the range of the provided timestamps, the value at the nearest endpoint is returned (i.e., the data is clamped).

DiscreteScenario gtsam::DiscreteScenario::FromCSV ( const std::string & csv_filepath)
static

Named constructor to create a scenario from a CSV file.

The CSV file should contain a header row followed by data rows. All timestamps will be normalized so that the first timestamp in the file corresponds to t=0 for the scenario.

CSV is expected to contain the following columns: t,q_w,q_x,q_y,q_z,v_x,v_y,v_z,p_x,p_y,p_z,w_x,w_y,w_z,a_x,a_y,a_z Other columns will be ignored.
