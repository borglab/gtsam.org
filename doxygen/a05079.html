gtsam::FlatGaussianFactor Class Referenceabstract

Detailed Description

Optional preindexed kernels for matrix-free Gaussian factors.

A GaussianFactor can additionally implement this interface so iterative solvers can apply it using scalar offsets and block slots compiled from the solver's ordering. This avoids rebuilding VectorValues and keyed maps in hot loops without changing the factor's ordinary GaussianFactor interface.
