gtsam::so3::DexpFunctor Struct Reference

Detailed Description

Functor that implements Exponential map and its derivatives Math extends Ethan theme of elegant I + aW + bWW expressions.

See https://www.ethaneade.org/lie.pdf expmap (82) and left Jacobian (83).

OptionalJacobian< 6, 6 > H = {} ) const

Apply the SO(3) left Jacobian to a tangent vector and optionally compute the complete right-trivialized Jacobian of the lifted [omega; v] exponential.

This is the shared exponential kernel for both SE(3) and TSO(3), whose translational/algebra component is J_l(omega) * v.
