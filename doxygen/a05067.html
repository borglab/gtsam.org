gtsam::FixedJacobianFactor< M, Ns > Struct Template Reference

Detailed Description

template<int M, int... Ns>
struct gtsam::FixedJacobianFactor< M, Ns >

A JacobianFactor whose residual and variable dimensions are known at compile time.

Fixed-size kernels are used for any number of variable blocks.
